# The Marlene File — Frontend prototype

React + Vite frontend based on the supplied 20-page PDF design brief.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the project folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Included
- Intro, Marlene welcome, detective name entry
- Investigation office and three case categories
- Nine selectable locations
- Evidence room with interactive timeline slider and trend chart
- Proof tabs, progress tracker, and investigation summary
- Responsive styling and animated CSS globe placeholder

## Important
All chart values and visual imagery in this first pass are illustrative placeholders, not verified scientific findings. Replace them with validated NASA/NSIDC datasets and the original Figma image assets before scientific presentation. The globe and portrait are CSS placeholders until the image assets are supplied.
