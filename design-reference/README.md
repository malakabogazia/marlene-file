# Design reference (not part of the website)

`graphs/` holds the graph pictures made by the team: one per case and one comparison per variable.
They are pictures only, so the website does not read numbers from them. It draws its own charts from the API,
which keeps the values exact and the charts interactive. These pictures were used as the reference for how the charts should look.

Two comparison files were uploaded with swapped names (the "Precipitation" file held the soil moisture graph and the other way round). They are now named after what they show.
